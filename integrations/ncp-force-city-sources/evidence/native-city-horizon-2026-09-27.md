The 256-drone maximum batch completed. The required 7,200-tick CPU case failed at its fixed 600-second session deadline.

## Frozen workloads

Both cases used 256 ordered drones and sixteen cuboids in the installed force-city environment.
The first control batch set every target. Later batches held those targets.
The fixed simulation rate was 120 Hz. Each session had an unchanged 600-second deadline.

The maximum case selected four RGB cameras, four thermal cameras, and four microphones for three ticks.
The CPU case selected no sensor sources and requested 7,200 ticks.
Its transcript option was disabled because the complete workload exceeds the existing 8,190-exchange capture limit.
The campaign preserved original requests and validated response projections for completed CPU calls.
Those projections are not original response frames.
