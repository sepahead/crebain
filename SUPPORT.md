# Support

Thank you for using CREBAIN. Use the resources below to get help.

## Questions and discussion

For usage questions or setup help, use
[GitHub Discussions](https://github.com/sepahead/crebain/discussions). You can
also discuss an idea there before you open an issue.

## Bugs and feature requests

Open an [issue](https://github.com/sepahead/crebain/issues/new/choose). Use the
bug-report form or the feature-request form. Include the information that the
form requests.

## Security vulnerabilities

Do **not** open a public issue. Follow the process in
[SECURITY.md](SECURITY.md) (GitHub private vulnerability reporting).

## Before asking

- Read the [README](README.md) and, for contributing, [CONTRIBUTING.md](CONTRIBUTING.md).
- For a frontend problem, run `bun run validate`.
- For a full application problem, run `bun run validate:all`.
- Confirm that the problem occurs in a clean checkout.
- This is a research prototype: model weights are not shipped, and performance,
  accuracy, and transport-latency numbers must be measured on your own target
  hardware (see the disclaimers in the README and `SECURITY.md`).
